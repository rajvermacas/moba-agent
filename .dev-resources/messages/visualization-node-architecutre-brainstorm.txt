● Summary: Tool Retry Behavior

  How Many Times Will the Agent Retry?

  1. Global Limit: Maximum 15 total agent-tool cycles (configurable)
    - Set via AGENT_RECURSION_LIMIT in constants
    - Prevents infinite loops at the graph level
    - After 15 cycles, LangGraph raises GraphRecursionError
  2. Per-Tool Limit: Maximum 3 consecutive errors for the same tool
    - Set via AGENT_MAX_CONSECUTIVE_TOOL_ERRORS
    - If same tool fails 3 times in a row, agent stops retrying that specific tool
    - Agent can still try other tools or approaches
  3. Smart Retry Behavior:
    - Agent observes each error message
    - Can correct arguments based on error feedback
    - Tracks errors per tool to prevent getting stuck
    - Provides user-friendly explanation when giving up

  Example Retry Flow:

  1. Agent calls execute_query_sales(table="productz")
  2. Tool returns error: "Table 'productz' not found"
  3. Agent sees error, retries: execute_query_sales(table="products")
  4. Tool returns error: "Column 'revenu' not found"
  5. Agent sees error, retries: execute_query_sales(table="products", column="revenue")
  6. Tool returns error: "Permission denied"
  7. Agent gives up: "I've tried execute_query_sales 3 times but it keeps failing. The last error was: Permission denied. Let me
  try a different approach..."

  This prevents infinite loops while still allowing intelligent error recovery!
